# Talos .level Editor

Welcome to the **Talos .level Editor**, a simple web app that lets you modify
your Talos `.level` files in your browser!
No software installation is required — everything runs right in your browser.

> ⚠️ **Warning**
>
> Modifying `.level` files can potentially corrupt them.
> **Always** back up your original file before making changes and proceed at your own risk.

## Features

- Apply each change individually.
- Resize your level beyond the default bounds: make it larger than 10×10 or shrink it down to 0×0.
- Switch or remove music entirely.
- Switch terrain style without auto-updating style for objects.
- Change or remove vegetation as you like.
- Increase fog density to dramatic levels.
- Fine-tune cloud layers.

## How to Use

1. **Load Your File**
   - Click on the file box or drag your ``.level`` file onto the page.
2. **Tweak Settings**
   - Numeric values (e.g., width, height, fog) can be typed in or adjusted in steps.
   - Choose from dropdowns for music, terrain style, and vegetation.
   - Click the **Set** button next to each field to apply changes.
3. **Download**
   - When you’re happy with your edits, hit **Download** to get your updated ``.level`` file.

### Tips
* Large maps with heavy vegetation may crash your game or load very slowly.
* Removed vegetation can't be restored — make sure you really want to clear it.
